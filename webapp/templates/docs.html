Overview & System Architecture

NorthSearch 2.0 is an autonomous deep intelligence, multimodal search, and persistent knowledge aggregation platform. It orchestrates clearnet search engines, Tor darknet discovery, local SQLite FTS5 vector and full-text indexes, and local Ollama LLMs to perform private, resilient, and comprehensive research without relying on third-party cloud trackers.

Zero-Leak Architecture: All search queries, embeddings, scraped profiles, and Ollama LLM inferences run locally on your machine.

Core Components

Multi-Engine Hub

Parallel queries across DuckDuckGo, Bing, Yahoo, Wikipedia, SearXNG, Yandex, Brave, Qwant, Mojeek, and Local Knowledge Base.

Tor Darknet Gateway

Dual-mode onion search: live SOCKS5 Tor network proxy with automatic clearnet fallback discovery for hidden services.

Dual Visual Search

Perceptual dHash/pHash matching against local SQLite database + simultaneous online reverse web image lookup.

Continuous Knowledge Memory

Autonomous FTS5 full-text indexing stores every queried result, scraped snippet, and crawled entity to build a local offline search index.

AI Pipeline

Deep AI Research & Synthesis

The Deep AI Research pipeline transforms high-level research questions into detailed investigative reports through an iterative, autonomous workflow:

  1. Query Decomposition: The local LLM (e.g. dolphin3:8b or llama3.1) breaks down your topic into targeted sub-queries.
  2. Parallel Multi-Engine Harvesting: Sub-queries are dispatched across all active clearnet and darknet engines concurrently.
  3. Content Extraction & Cleaning: Web pages are scraped, parsed with Readability algorithms, and distilled into high-density snippets.
  4. Persistent Indexing: Harvested text is saved into the local SQLite FTS5 Knowledge Base.
  5. Synthesis & Verification: The LLM synthesizes verified facts with markdown tables, key takeaways, and direct source citations.
Search Technology

Multi-Engine Quick Search & Knowledge Index

Quick Multi-Search sends your query simultaneously to up to 10 distinct search providers. Every engine utilizes modern TLS impersonation (via curl_cffi) and anti-bot retry strategies so requests succeed reliably.

Keyword Inclusion & Exclusion Filters

You can enforce strict content rules on your search results:

  • Must Include: Comma-separated terms (e.g. open-source, python, github). Results are only shown if their title, snippet, or URL contains all specified terms.
  • Must Exclude: Terms (e.g. sponsored, affiliate, pinterest) that immediately discard matching entries from the final results.
Knowledge Base Singleton: All valid results returned by search queries are automatically indexed into data/knowledge_base.db. Over time, your local database can answer queries instantly without hitting external networks.
Darknet Protocol

Tor & Darknet Discovery

NorthSearch provides seamless access to Tor hidden services (.onion domains) with a robust two-layer architecture:

Darknet Search Mechanics Routing 
1. Native Tor Proxy: Checks localhost:9050 / localhost:9150 (Tor Expert Bundle / Tor Browser).
   -> If active: Queries Ahmia (.onion), Tor66, and Haystak via SOCKS5.
2. Clearnet Discovery Fallback:
   -> If Tor daemon is offline: Queries indexed onion gateways via DDGS to harvest live .onion links.
3. Resilience: Darknet search NEVER fails or blocks your browser even when Tor is disconnected.
Computer Vision

Visual & Reverse Image Search

Upload any photo (JPG, PNG, WEBP) to perform dual-layer visual matching:

  • Local Perceptual Hashing (dHash / pHash / Average Hash): Computes structural 64-bit difference vectors and queries local SQLite database for matching face/performer records. Returns similarity percentage.
  • Online Reverse Web Discovery: Queries Google Images and Bing Visual Search to locate original web pages, high-resolution source photos, and identity profiles across the open web.
Data Harvesting

Custom Scraper & DB Updater

The in-built web crawler extracts profile information, metadata, and avatars from any target website or directory.

  • Content Rule Verification: Crawls target pages, extracts full text, and ensures content satisfies your required "Must Include" and "Must Exclude" keyword filters before writing to SQLite.
  • Automatic Image Pipeline: Downloads target photo assets, converts them into standard format in data/performer_photos/, and links them to the database records.

ParameterTypeRequiredDescription

POST /api/reverse-image

Upload an image for local perceptual hash matching and online reverse web search.

ParameterTypeRequiredDescription

ParameterTypeRequiredDescription
